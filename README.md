# โครงการวิจัยเพื่อพัฒนาคุณภาพบริการสุขภาพ (QIR: What, Why, and How)

สไลด์ประกอบการเรียนการสอนเชิงโต้ตอบ (Peitho Deck Engine) พร้อมบทบรรยายรายสไลด์แบบ 1 ต่อ 1 และเอกสารคำสอนแบบ Guided Learning ฉบับสมบูรณ์ สำหรับรายวิชาเวชศาสตร์ชุมชน ชั้นปีที่ 5 (การฝึกปฏิบัติงานโรงพยาบาลชุมชน 4 สัปดาห์)

**ผู้จัดทำ:** นพ.ณัฐวุฒิ เอี่ยงธนรัตน์ · ภาควิชาเวชศาสตร์ชุมชน คณะแพทยศาสตร์โรงพยาบาลรามาธิบดี มหาวิทยาลัยมหิดล

## คุณสมบัติหลักของสไลด์นำเสนอ

1. **ปุ่ม `บทบรรยาย · แสดง/ซ่อน` ด้านล่างสไลด์ (`B` หรือ `Shift+N`):** เปิดแผงสคริปต์คำบรรยายแบบกระชับตรงกันแบบ 1 ต่อ 1 กับทุกจังหวะขั้นของสไลด์ โดยย่อพื้นที่เวทีสไลด์อัตโนมัติไม่ให้บังเนื้อหา
2. **โหมดอ่านพร้อมบทบรรยาย (`R`):** แสดงสไลด์ทั้ง 25 สไลด์เรียงต่อเนื่องพร้อมบทบรรยายครบทุกขั้นสำหรับทบทวนด้วยตนเอง
3. **หน้าต่างผู้บรรยายจอที่สอง (`n`):** เปิดหน้าต่างแยกพร้อมนาฬิกาจับเวลาเทียบแผนการสอนและตัวอย่างสไลด์ถัดไป
4. **สลับธีมมืด / สว่าง (`T`) และสารบัญภาพรวม (`O`):** รองรับทั้งการฉายโปรเจกเตอร์ในห้องประชุมและการอ่านบนแท็บเล็ตหรือโทรศัพท์มือถือ
